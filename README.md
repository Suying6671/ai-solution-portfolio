# 万舒畅企业 AI 个人主页

面向企业 AI、AI 产品与 FDE 岗位的单页个人作品集，展示真实客户项目、Agent / Workflow 搭建方法、客户交付经历与量化成果。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:3000/`。

## 完整验证

```bash
npm run lint
npm test
```

## 内容维护

- 主要文案与案例数据：`content/profile.ts`
- 首页结构：`app/page.tsx`
- 页面样式：`app/globals.css`
- 公开图片与简历：`public/`

项目使用 React 19、TypeScript 与 Vinext 构建。
